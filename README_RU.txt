NIGHTMARE: THE SCHOOL
=====================

КАК ЗАПУСТИТЬ В WINDOWS / VS CODE

1. Распакуй NIGHTMARE_SCHOOL.zip в удобное место, например на Рабочий стол.
2. Открой VS Code.
3. Нажми File -> Open Folder и выбери папку NIGHTMARE_SCHOOL.
4. Открой Extensions (иконка кубиков слева).
5. Найди расширение Live Server (автор Ritwick Dey) и установи его.
6. Открой index.html.
7. Нажми правой кнопкой по index.html -> Open with Live Server.
8. В браузере откроется игра.

УПРАВЛЕНИЕ
W A S D — движение
Мышь — осмотр
SHIFT — бег
F — фонарик
E — подобрать ключ / попытаться открыть выход
ESC — отпустить мышь / пауза браузера

ВАЖНО
- Для загрузки Three.js нужен интернет, потому что библиотека подключается через CDN.
- Готовые 3D-модели не используются: школа, мебель и существо создаются из геометрии Three.js.
- Если экран чёрный: открой игру через Live Server, а не двойным щелчком по index.html.
